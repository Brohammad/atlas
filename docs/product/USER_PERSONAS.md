# Users

No interviews have been run. These are working assumptions for the regression cohort. The first 20 sittings confirm or kill them. Names are roles, not people.

## Primary — working engineer, new to the mechanism

Can write Python and read an API. Has called `fit` or watched someone do it. Cannot derive a squared-error gradient or explain a diverging learning rate. Has a job, so a sitting has to be about fifteen minutes, on a phone between other work, and worth finishing without an account.

Wants a story they can defend in an interview or a design review: "I computed the step, and I know which bug sends it uphill."

Will leave if the page opens with a video, a textbook chapter, or a module map of 140 unbuilt lessons. Will also leave if the question is a slogan with four paraphrases.

Success for this person: they miss a station, read the idea, and get an unseen case right. Completion without a miss is a weak signal, because the answers are in the client.

## Secondary — the author as the first learner

Uses the same units to find weak questions. A question that the author can answer from memory of the option text is a bad question. The useful failure is a distractor that is a real wrong procedure and still gets chosen for the wrong reason, or a distractor nobody chooses because it is absurd.

This persona must not be the only source of "it works." The author clearing 8 of 8 is not a pilot.

## Anti-persona — certificate collector

Wants hours, a badge, and a syllabus that looks like a master's course. Serves the 12-module inventory. Atlas should disappoint them on purpose. We do not add quizzes that can be passed by recognizing a definition.

## Anti-persona — research scientist

Wants proofs, measure theory, and a general treatment of empirical risk minimization before a line. Atlas will use the derivative when the step needs it. We will not open with a foundations module to satisfy this reader.

## Payer hypotheses

Unvalidated. Do not build for these until the primary persona finishes.

- The engineer pays for a finished track and a result they can show.
- An employer pays for a shared assessment with a hidden answer key and a proctoring story we do not have.
- A bootcamp pays to embed a unit. Likely a distraction. One embed deal is not product-market fit with engineers.

The cohort tests the first hypothesis only, and only after finish rate and return rate exist.
